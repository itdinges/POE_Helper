# Documentation

This folder tracks what this project is, what it does today, and where it is going.

## Purpose

POE Helper is a local-first helper for Path of Exile 2 with an initial focus on loot filter workflow.

## Scope

In scope:

- local filter file discovery
- managed rule insertion
- repeatable regeneration of managed output files

Out of scope:

- gameplay automation
- client memory modification
- anti-cheat bypassing

Requirements are expected to evolve. Keep this documentation practical and update it as decisions become clearer.
