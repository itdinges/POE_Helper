# ADR Index

Architectural Decision Records (ADRs) capture technical decisions and their context.

## How To Use ADRs

- Create one ADR per major decision.
- Keep status up to date: Proposed, Accepted, Superseded.
- Link follow-up ADRs when decisions evolve.

## Naming

Use incremental numbering: 0001, 0002, 0003.
