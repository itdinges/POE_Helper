# Domain Dictionary

This folder is the source of truth for the gameplay language used by the helper.

The goal is to define terms from the player’s actual in-game experience before building logic or UI around them.

## Purpose

This is not just documentation. It is a domain definition layer.

It keeps the project grounded in:

- what the player sees in-game
- what the market actually means
- what a vendor action means
- what a profitable loop looks like for a fresh start

## Included artifacts

- [GLOSSARY.md](GLOSSARY.md) — domain terms and the specific definitions used by the project
- [screenshots/README.md](screenshots/README.md) — where visual examples and gameplay screenshots belong

## Working rule

If a concept is not supported by a real in-game example or screenshot, it should not be treated as a project requirement yet.
