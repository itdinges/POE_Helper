# Screenshot Evidence Folder

This folder contains visual proof for the domain terms used by the project.

## Purpose

Use screenshots here to ground the project in actual in-game behavior.

Add examples for:

- market price examples
- vendor cost examples
- vendor-to-market spread examples
- fresh-start affordability examples
- trade route examples
- price drift over time

## Naming convention

Use clear names like:

- market_sell_price_example.png
- vendor_cost_example.png
- vendor_to_market_spread_example.png
- fresh_start_chaos_affordability.png
- timeline_value_drift_example.png

## Rule

A screenshot should support a definition in the glossary. If a screenshot does not explain a concept clearly, it should be renamed or replaced.

## Current status

This folder is intentionally a place for evidence and examples, not a generated output directory.
